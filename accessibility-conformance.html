Accessibility conformance report (draft)

Draft Section 508 / WCAG 2.1 AA accessibility conformance report (VPAT 2.x format) for the ravonics.com public website.

Read related work Engage with team

VPAT 2.x · WCAG 2.1 edition · Draft

Report scope

  • Product: the ravonics.com public website (all published routes).
  • Standards: WCAG 2.1 Level A and AA, which Section 508 (36 CFR 1194) incorporates for web content.
  • Evaluated: 2026-11-22. Contact: contact@ravonics.com.

Evaluation methods

Every change to the site runs a route contract in continuous integration: each published route is loaded in Chromium and checked with axe-core for WCAG A and AA rules, a single main landmark and h1, a page title, broken images, horizontal overflow and reflow at 320 pixels wide. On the main contact routes a keyboard walk checks that the Tab key reaches every control, leaves the page after the last one and shows where focus is. Criteria marked Not Evaluated still need a manual review with keyboard and screen-reader testing. This report is a draft until that review is complete; it will not claim more than the evidence shows.

Summary: 14 Supports · 29 Not Evaluated · 4 Not Applicable · 3 Partially Supports across 50 Level A and AA success criteria.
