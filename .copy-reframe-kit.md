### 1.3 Edge-Case Guidance — Program and Standard Proper Nouns

These terms have "DoD" embedded in their own proper names and are governed by their own naming authorities. Apply caution:

| Term | Action | Reason |
|---|---|---|
| `CMMC` (Cybersecurity Maturity Model Certification) | **KEEP unchanged** | CMMC is a proper program name under 32 CFR Part 170. The program has not been renamed. Write "CMMC" never "DoW CMMC." |
| `DoD Impact Level (IL5 / IL6)` | **RENAME to "DoW Impact Level (IL5)"** | Industry usage (e.g., Zscaler press releases as of 2026) already uses "DoW Impact Level 5." The DISA framework name follows the department name. |
| `JADC2` (Joint All-Domain Command and Control) | **KEEP unchanged** | Program proper noun; has not been renamed. |
| `NIST 800-171`, `NIST 800-207`, `NIST 800-53` | **KEEP unchanged** | NIST standards are independent of the department name. |
| `FedRAMP` | **KEEP unchanged** | GSA-governed program, not DoW-named. |
| `DoD CDAO Tradewinds` | **RENAME to "DoW CDAO Tradewinds"** | The CDAO is a DoW office; the program follows the department name. |
| `DoD cybersecurity requirements` (generic) | **RENAME to "DoW cybersecurity requirements"** | This is a descriptor of the department, not a named standard. |
| `ITAR` / `EAR` / `DDTC` | **KEEP unchanged** | State Department / Commerce programs, not DoW. |
