# COPY-ONLY REWRITE PROTOCOL — Ravonics enterprise template

This is a **purchased enterprise template**. The layout, CSS, and per-area character
budgets are deliberate and **paid for**. We are doing a **copywriting pass only**.

## THE IRON RULE — you may change TEXT NODES ONLY

You may ONLY edit the human-readable text that sits *between* existing tags, plus the
text *value* of meta/Schema fields. You may NOT change anything structural.

### ALLOWED
- Text between tags: `<h3>OLD TEXT</h3>` → `<h3>NEW TEXT</h3>`
- `content="..."` values of `<meta>` tags (title/description/keywords/OG/Twitter)
- The `<title>` text
- Text *values* inside JSON-LD (e.g. `"streetAddress": "..."`, `"name": "..."`)
- Removing a fabricated JSON-LD *fact block* that has no honest equivalent
  (only `aggregateRating` and held-cert `hasCredential` entries — see below)

### FORBIDDEN (this is what got the last attempt rejected)
- ❌ NO changes to `<style>` blocks or any CSS — not one property
- ❌ NO new/edited `class=` or `id=` attributes; do not retag elements
- ❌ NO adding or removing `<div>`, `<section>`, cards, columns, rows, list items
- ❌ NO changing the **number of cards / slots / testimonials / team members**
- ❌ NO changing Bootstrap grid classes (`col-lg-*`, `row`, etc.)
- ❌ NO changing `<img src>`, icons, links structure, or component types
  (e.g. do not turn a carousel into a static section)
- ❌ NO dramatic length changes. Stay within **~±15%** of the original text length
  for each element. The template was tuned for these character counts.

### ACCEPTANCE GATE
After edits, the orchestrator runs a structural fingerprint (counts of `<div`,
`class=`, `<style`, `col-*`). **If any count changes for any file, the work is
rejected.** Text-only edits leave the fingerprint identical.
